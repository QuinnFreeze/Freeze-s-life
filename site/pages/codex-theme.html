Codex 玻璃主题

我为 macOS Codex 开发的玻璃主题，支持自定义壁纸，并提供本地设置页面。

主要功能

  • 壁纸与画面

    支持本地图片，以及位置、填充方式、亮度与模糊等设置。

  • 玻璃界面

    为输入区域、菜单与浮动面板添加玻璃质感，并跟随应用的浅色或深色外观。

  • 可视化设置

    通过本地设置页选择和预览壁纸，调整浅色界面透明度，也可以恢复默认壁纸。

  • 独立加载

    主题通过独立启动器和本地调试接口加载，保留官方应用及其签名文件。

技术构成

  • Python

    负责安装、主题管理和本地插件工具。

  • JavaScript / Node.js

    负责主题运行器与本地调试连接。

  • CSS 与 HTML

    CSS 定义玻璃样式；HTML 承载壁纸设置界面。

  • Objective-C 与 Shell

    用于 macOS 启动器、观察器与安装启动入口。
