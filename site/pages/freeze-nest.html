秋易的小窝

这个小窝是我的个人网站，用于集中展示个人简介、关注方向与公开项目。源码发布在 Freeze-s-life 仓库。

主要功能

  • 基本资料与兴趣

    展示我的姓名、格言、个人简介与兴趣，并按生日自动计算年龄。

  • 中英文阅读

    可以切换中文与英文，保存语言偏好，也可用链接指定页面语言。

  • 适应不同屏幕

    同一套内容适应手机、平板和桌面，保留壁纸与轻量玻璃样式。

  • 直接联系

    提供邮箱与社交入口，可通过 WhatsApp 用户名链接联系我。

技术构成

  • HTML

    承载页面结构与实际内容，基本资料和链接无需 JavaScript 也可阅读。

  • CSS

    处理响应式排版、透明玻璃样式，以及减少动态效果和透明度的系统偏好。

  • JavaScript

    处理语言切换与按生日计算的年龄，不依赖前端框架。

公开源码

网站采用原生 HTML、CSS 和 JavaScript 构建。Freeze-s-life 仓库同时提供本地检查脚本与 GitHub Pages 部署配置。
